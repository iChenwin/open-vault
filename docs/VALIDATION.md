# v0.1.0 预览版验证记录

验证日期：2026-10-21。以下记录区分已经执行的验证与发布后仍需完成的部署验证。

## 已执行

- Windows amd64，Go 1.25.5：`go test ./...`、`go vet ./...`、界面 JavaScript 语法检查。
- Ubuntu 24.04 / WSL2，Linux amd64，restic 0.16.4：运行交叉编译的 Go 测试程序。
- 引擎真实恢复：初始化加密仓库 → 备份文件 → 修改文件并再次备份 → 确认两个版本 → 删除源文件 → `check --read-data` → 将最初版本恢复至新目录 → 逐字节比对原内容。
- API 真实恢复：通过 HTTP handler 发起初始化、创建任务、备份、快照查询、完整校验和异步恢复，核对最终记录及恢复内容。
- 认证、无效输入、任务状态持久化、暂停和删除、并发操作拒绝、调度间隔、禁用任务、服务中断后的记录恢复。
- 源路径允许范围、符号链接越界、凭据权限、恢复目录重叠、路径穿越、覆盖已有恢复目标和响应大小限制。
- Linux amd64 可执行文件交叉构建。

真实集成测试必须显式配置 restic，否则常规单元测试会跳过该部分：

```sh
RESTIC_TEST_BINARY="$(command -v restic)" go test -count=1 -v ./...
```

GitHub Actions 配置在 Linux 上执行 `go vet`、带 race detector 的测试、真实 restic 集成和构建；其远端结果以仓库 Actions 页面为准。

## 尚未覆盖

Docker 镜像运行、systemd 实机安装、真实浏览器视觉与键盘验收、大规模或长时间压力测试、NAS 掉线、磁盘耗尽、恶意文件系统并发替换、外部安全审计和整机灾难恢复尚未完成。非 root 恢复的所有权、特殊文件及扩展属性需要按部署环境演练。本版本适用于隔离环境试用和验证，不提供生产 SLA。
