开发验证版：内核实验发现增量恢复镜像不一致，修复尚未通过验收。请仅使用可销毁的测试数据；仓库校验通过不代表源卷已被完整备份。

首次使用：页面打开后，怎样开始？
  1. 能登录说明控制台已启动；同一局域网可使用服务器 IP 和端口访问。
  2. 如果显示「未配置」，需要先在 Ubuntu 测试机准备数据卷服务。控制台不会自动修改磁盘或安装内核驱动。
  3. 数据卷服务连接后，先建立首次备份，再选择版本恢复为新镜像，并独立检查恢复内容。
